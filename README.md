# Ухаалаг Кофе шопын NFC-д суурилсан Захиалгын Систем

Кофе шопын ширээнд суусан хэрэглэгч NFC шошгыг утсаар уншуулснаар цахим цэс нээж, захиалгаа өгч, төлбөр төлснөөр захиалгаа ширээндээ авах системийн **төслийн бичиг баримт** (LaTeX).

> Одоогоор энэ репозитойд зөвхөн төслийн баримт бичиг байгаа бөгөөд системийн программ хангамжийн хөгжүүлэлт дараагийн үе шатанд хийгдэнэ.

    │   ├── ch4-udirdlaga.tex     # ДӨРӨВ. Удирдлага, хүний нөөцийн төлөвлөгөө

### Бүлгүүдийн товч агуулга

| Бүлэг | Агуулга |
|---|---|
| **НЭГ. Төслийн танилцуулга** | Суурь үзүүлэлтүүд, хэрэгжүүлэгч, бүтээгдэхүүний танилцуулга, зорилго, ач холбогдол |
| **ХОЁР. Нөхцөл байдлын шинжилгээ** | Макро/микро орчин, өрсөлдөгчийн харьцуулалт (NFC vs QR vs Kiosk vs апп), SWOT |
| **ГУРАВ. Маркетингийн төлөвлөгөө** | Зорилтот зах зээл, 4P шинжилгээ, нэг удаагийн багц үнэ (стикер сет + систем + тохиргоо) |
| **ДӨРӨВ. Удирдлага, хүний нөөц** | Багийн бүтцийн диаграмм, ажиллах хүчний тооцоо, цалингийн төлөвлөгөө |
| **ТАВ. Системийн загвар** | Урсгалын диаграмм, 3-давхаргат архитектур, ER диаграмм, REST API, аюулгүй байдал, хөгжүүлэлт/туршилтын төлөвлөгөө |
| **ЗУРГАА. Санхүүгийн төлөвлөгөө** | Хөрөнгө оруулалт, үйл ажиллагааны зардал, орлогын тооцоо, ROI, зээлийн график |
| **ДОЛОО. Төслийн дүгнэлт** | Урьдчилсан нөхцөл, хүлээх үр дүн, эрсдэлийн үнэлгээ |

## Хэрхэн компайл хийх вэ

**Шаардлагатай:** XeLaTeX (Windows дээр [MiKTeX](https://miktex.org), macOS/Linux дээр [TeX Live](https://tug.org/texlive)).

Анхаарна уу: баримт бичигт кирилл фонтууд (Times New Roman, Arial) болон TikZ диаграммууд ашигласан тул **зөвхөн XeLaTeX**-ээр компайл хийнэ (pdfLaTeX биш).

```bash
# docs хавтсанд орж, 2 удаа ажиллуулна (агуулга, холбоосууд зөв үүсэхийн тулд)
cd docs
xelatex main.tex
xelatex main.tex
```

Компайл амжилттай бол `docs/main.pdf` файл үүснэ (~27 хуудас).

### Дэд бүтэц / шаардлагатай багцууд

Компайлын үед шаардагдах үндсэн багцууд: `fontspec`, `babel` (mongolian), `geometry`, `setspace`, `booktabs`, `tikz`, `titlesec`, `fancyhdr`, `hyperref`, `amsmath`. MiKTeX ашиглаж байгаа бол дутуу багцыг автоматаар татаж авна.

## Гол техникүүд (Тавдугаар бүлэгт)

- **Хэрэглэгчийн апп:** React PWA — тусгай апп таталгүйгээр NFC шошгыг арын дэвсгэртэд уншиж, цэс нээнэ
- **Сервер:** NestJS (REST API + WebSocket бодит цагийн мэдэгдэл)
- **Өгөгдлийн сан:** PostgreSQL (үндсэн), Redis (cache/queue)
- **Төлбөр:** QPay / SocialPay / карт процессингийн интеграци
- **Нэвтрүүлэг:** Docker
